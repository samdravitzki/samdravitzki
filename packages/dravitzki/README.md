## Commands

### Generating a new dravitzki.com project

To generate a new skeleton for a dravitzki.com project run...
```npm run plop project```

You will be prompted with the required parameters

The idea being to take out the step of actually creating the boiler plate for a new project as it
can be time consuming and distracting, allowing me to stay focused on creating whatever it is I am
actually wanting to create.
